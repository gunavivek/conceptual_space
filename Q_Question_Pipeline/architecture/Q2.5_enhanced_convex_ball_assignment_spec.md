## Fallback Strategy Architecture

### Non-Containment Problem Resolution

The fundamental challenge you identified - questions falling outside ALL convex balls - is addressed through a hierarchical fallback system:

#### 1. Exact Containment (Best Case)
```python
if distance <= radius:
    membership_strength = 1.0 - (distance / radius)
    containment_type = "exact"
    confidence = 1.0
```

#### 2. Radius Expansion Fallback
```python
if distance <= radius * expansion_limit:
    expansion_factor = distance / radius
    confidence_penalty = (expansion_factor - 1.0) / (expansion_limit - 1.0)
    adjusted_confidence = 1.0 - (confidence_penalty * 0.5)
    containment_type = "radius_expansion"
```

#### 3. Nearest Neighbor Projection
```python
direction = (question_coords - centroid) / norm(question_coords - centroid)
projected_coords = centroid + direction * radius
projection_confidence = f(projection_distance)
containment_type = "nearest_neighbor_projection"
```

#### 4. Semantic Similarity Fallback (Emergency)
```python
semantic_similarity = cosine_similarity(question_embedding, ball_text_embedding)
fallback_membership = semantic_similarity * 0.5  # Reduced confidence
containment_type = "semantic_similarity"
confidence_penalty = 0.7  # High penalty for semantic fallback
```

## Core Architecture Components

### 1. ConvexBallContainmentManager

```python
class ConvexBallContainmentManager:
    """Manages convex ball containment detection and fallback strategies"""

    def detect_containment_status(self, question_coords: np.ndarray,
                                  convex_balls: Dict, dimension_type: str) -> Dict:
        """
        Detect if question coordinates fall within any convex ball
        Returns: {contained_balls, near_miss_balls, distant_balls, containment_status}
        """

    def apply_radius_expansion_fallback(self, question_coords: np.ndarray,
                                       near_miss_balls: List[Dict],
                                       dimension_type: str) -> FallbackResult:
        """Apply radius expansion with confidence penalties"""

    def apply_nearest_neighbor_projection(self, question_coords: np.ndarray,
                                         all_balls: List[Dict],
                                         dimension_type: str) -> FallbackResult:
        """Project question to nearest ball boundary"""

    def apply_semantic_similarity_fallback(self, question_text: str,
                                         convex_balls: Dict,
                                         dimension_type: str) -> FallbackResult:
        """Emergency fallback using basic semantic similarity"""
```
