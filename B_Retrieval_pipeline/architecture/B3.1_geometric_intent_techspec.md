## 1. Module Overview

### Purpose
Implement geometric distance and angular calculations in concept space for intent-driven question-chunk matching.

### Key Functions
- `map_to_concept_space()`: Convert entities to geometric coordinates
- `calculate_geometric_distance()`: Compute Euclidean distance with intent weighting
- `calculate_concept_angles()`: Measure angular separation from concept centroids
- `associate_question_to_chunks_geometric()`: Main orchestration function

## 3. Algorithm Specifications

### 3.1 Coordinate Mapping Algorithm

```python
Algorithm: Map to Concept Space
Input: entity (question/chunk), concept_memberships
Output: coordinate_vector

1. Initialize n-dimensional zero vector (n = total concepts)
2. For each concept in global concept list:
   a. If concept has membership score:
      - Set coordinate[i] = membership_score
   b. Else:
      - Set coordinate[i] = 0.0
3. Return coordinate_vector
```

### 3.2 Geometric Distance Calculation

```python
Algorithm: Calculate Intent-Weighted Distance
Input: Q (question coords), C (chunk coords), I (intent vector)
Output: weighted_distance, intent_alignment

1. Calculate base Euclidean distance:
   d_base = sqrt(sum((Q[i] - C[i])^2))

2. Calculate chunk direction vector:
   direction = C - Q

3. Calculate intent alignment:
   if ||direction|| > 0:
     alignment = dot(I, direction) / (||I|| * ||direction||)
   else:
     alignment = 1.0

4. Apply intent weighting:
   weight = 0.5 + 0.5 * alignment
   weighted_distance = d_base / weight

5. Return (weighted_distance, alignment)
```

### 3.3 Angular Analysis Algorithm

```python
Algorithm: Multi-Centroid Angular Analysis
Input: Q (question), C (chunk), centroids (list)
Output: angles (dict)

1. For each centroid K in centroids:
   a. Calculate vectors from centroid:
      v_q = Q - K
      v_c = C - K

   b. Calculate angle:
      if ||v_q|| > 0 and ||v_c|| > 0:
        cos_angle = dot(v_q, v_c) / (||v_q|| * ||v_c||)
        angle = arccos(clamp(cos_angle, -1, 1))
      else:
        angle = 0.0

   c. Store angles[centroid_id] = angle

2. Return angles
```

### 3.4 Concept Ball Filtering

```python
Algorithm: Filter Chunks by Concept Balls
Input: chunks, primary_concepts, threshold=0.3
Output: filtered_chunks

1. For each chunk in chunks:
   a. Get chunk's concept memberships
   b. Check intersection with primary_concepts
   c. If any membership > threshold:
      - Include chunk in filtered set

2. Return filtered_chunks
```

### 4.3 Error Handling

```python
Errors to Handle:
1. Missing input files → Log warning, use empty defaults
2. Inconsistent concept dimensions → Pad with zeros
3. Invalid membership scores → Clamp to [0,1]
4. Numerical instability in angles → Clamp cosine values
5. Empty concept balls → Fall back to all chunks
```

### 4.4 Performance Optimizations

1. **Vectorization**: Use NumPy arrays for all calculations
2. **Pre-computation**: Cache concept centroids and dimensions
3. **Early Filtering**: Apply concept ball constraints first
4. **Batch Processing**: Process multiple chunks simultaneously
5. **Sparse Representations**: Use sparse matrices for large concept spaces

### 5.3 Validation Criteria

1. **Geometric Properties**:
   - Distance symmetry: d(A,B) = d(B,A)
   - Triangle inequality: d(A,C) ≤ d(A,B) + d(B,C)
   - Non-negativity: d(A,B) ≥ 0

2. **Angular Properties**:
   - Angle bounds: 0 ≤ θ ≤ π
   - Angle symmetry for same centroid

3. **Performance Requirements**:
   - Process 20 questions in < 2 seconds
   - Memory usage < 500MB
   - Accuracy contribution to 75-80% target
